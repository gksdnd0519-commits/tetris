# 테트리스

브라우저에서 바로 실행되는 단일 파일 테트리스 게임입니다. `index.html`을 열기만 하면 됩니다.

## 조작법

| 키 | 동작 |
|---|---|
| ← → | 좌우 이동 |
| ↑ / X | 시계 방향 회전 |
| Z | 반시계 방향 회전 |
| ↓ | 소프트 드롭 |
| Space | 하드 드롭 |
| C / Shift | 홀드 |
| P / Esc | 일시정지 |
| Enter | 시작 / 재시작 |

모바일에서는 화면 아래 터치 버튼으로 조작할 수 있습니다.

## 기능

- 7-bag 랜덤 블록 생성
- 고스트 블록, 다음 블록 미리보기, 홀드
- 레벨이 오를수록 빨라지는 낙하 속도 (10줄마다 레벨 업)
- 최고 점수 저장 (localStorage)
